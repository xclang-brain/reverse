# reverse Constitution

## Core Principles

### I. 要求管理は IPA「AI時代の要求管理ハンドブック」に準拠する

本リポジトリで行うすべての開発（仕様策定・計画・実装・テスト・運用・変更）は、
IPA デジタル＆AIシステムズ・デザインセンター（DADC）が公開した
「AI時代の要求管理ハンドブック ～経営・現場・開発がともに描く、問いから実現への道筋～」
に準拠して進める。

- 原典（PDF）: https://www.ipa.go.jp/digital/kaihatsu/rqr7mi000000f5up-att/req-mgmt-hb.pdf
- 公式ページ: https://www.ipa.go.jp/digital/kaihatsu/youkyu-kanri.html

具体的な考え方・手順・成果物は本書に記載しない。判断が必要な場面では、
その都度上記 PDF の該当箇所を参照し、それに従うこと。
ハンドブックは改訂される前提のため、参照時点の最新版を正とする。

### II. テーラリング

ハンドブックの活動・成果物は、プロジェクトの規模・リスク・変動性に応じて
ハンドブックの「実プロジェクトでのテーラリング」の考え方に沿って取捨選択してよい。
省略や簡略化を行った場合は、その判断と理由を残すこと。

## Governance

- 本 Constitution は、本リポジトリにおける他のあらゆる開発ルールに優先する。
- 本 Constitution の変更は、変更理由を明記したうえで行い、バージョンを更新する。
