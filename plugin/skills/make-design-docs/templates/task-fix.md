## 問題ごとの直し方

| 問題 | 直し方 |
| --- | --- |
| `missing_file` | そのファイルを、同じフォルダのほかのファイルと同じ形で書く。 |
| `missing_heading` | 「詳しい内容」の見出しを足し、内容を書く。当てはまる内容がなければ「該当する内容はない。」と書く。 |
| `too_long` | 内容を変えずに、重複や冗長な説明を減らして 1,000 行以下にする。 |
| `broken_link` | リンクの先を正しいパスに直す。先がないときは、リンクをやめて文字だけにする。 |
| `bad_marker` | 印を `【既存設計書のみ】` に直す。 |
| `bad_mermaid` | Mermaid のブロックの1行目を、図の種類（`flowchart TD`、`sequenceDiagram`、`stateDiagram-v2` など）にする。閉じていないブロックは閉じる。 |
| `duplicate_id` | 重なっている要求の ID の片方を、そのファイルで使われていない次の番号に変える。 |
| `evidence_location` | `<ファイル名>:<行番号>` の形の記述を消す。 |
