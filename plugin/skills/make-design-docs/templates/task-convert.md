## ページの目印

各ページの内容の前に、次の形の行を書く。N は、上の表のページの番号である。

```
<!-- page: N -->
```

## 拡大した画像の作り方

文字が小さくて読めないときは、次のコマンドを実行し、結果の `file` の画像を読む。

```
{{zoom_command}}
```

`<範囲>` には、`top`（上半分）、`bottom`（下半分）、`left`（左半分）、`right`（右半分）、または `x0,y0,x1,y1`（ページの幅と高さに対する 0〜1 の割合）を書く。
