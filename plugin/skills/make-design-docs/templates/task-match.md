## 記録の形

次の形で書く。2つの `## ` の見出しは、項目がなくても書く。

```markdown
# 照合の記録

## 食い違い

### <題>
- 既存の設計書の記述: <内容>
- ソースコードの内容: <内容>
- 既存の設計書での場所: <文書名とページ>
- ソースコードでの場所: <ファイル名と関数名>
- モジュール: <モジュールの ID または 全体>

## 既存の設計書にしかない内容

### <題>
- 内容: <内容>
- 既存の設計書での場所: <文書名とページ>
- モジュール: <モジュールの ID または 全体>
```

項目のキーは、上のとおりに書く。キーと値の間は、半角の `: ` で区切る。値は1行で書く。
